# Restricciones


| ID | Restricción | Consecuencia |
|---|---|---|
| R-01 | Flutter/Dart para móvil y panel; TypeScript para backend | Mantener las tecnologías existentes. |
| R-02 | Android como plataforma móvil inicial | iOS necesita entorno y validación específicos. |
| R-03 | Firebase para identidad, datos, archivos y funciones | Configurar permisos, índices, costos y despliegues por separado. |
| R-04 | Dinero y estados críticos controlados por servidor | El cliente envía solicitudes, no saldo o comisión final autoritativa. |
| R-05 | Servicios cartográficos requieren conectividad | El backend consulta rutas con conectividad y comunica fallos. |
| R-06 | No publicar secretos ni expedientes | Mantener archivos privados fuera de GitHub. |
| R-07 | Separación de prueba y operación | Las pruebas declaran su entorno y adaptadores. |
| R-08 | Ubicación necesaria para operar conectado como conductor | Desconectar y bloquear respuestas cuando se desactiva. |
