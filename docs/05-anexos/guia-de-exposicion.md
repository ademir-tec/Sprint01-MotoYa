# Guía breve para exponer

La explicación sigue los cuatro bloques de la entrega.

| Momento | Qué explicar | Frase sencilla |
|---|---|---|
| Problema | Distancia a paraderos y coordinación del recojo. | Pido la moto desde donde estoy y me preparo mientras llega. |
| Análisis | Usuarios y funciones del sistema. | Los requisitos expresan qué necesita cada actor. |
| Estilo | Comunicación entre aplicaciones. | App y panel son clientes; Cloud Functions es el servidor. |
| Enfoque | Reglas de dependencia internas. | Las reglas no dependen de Flutter ni Firebase. |
| Cotización | Responsabilidad del servidor. | El backend consulta la ruta, obtiene los km y calcula el precio. |
| Diseño | Búsqueda y aceptación de ofertas. | El caso de uso utiliza un contrato y el adaptador lo implementa. |
| C4 | Ampliación progresiva. | Primero el sistema, después aplicaciones, componentes y clases. |
| Calidad | Situaciones y criterios medibles. | Cada escenario tiene una respuesta y una herramienta para comprobarla. |
